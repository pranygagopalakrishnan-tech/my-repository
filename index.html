About the Workshop

Welcome to our GitHub Workshop! This workshop is designed for students and beginners who want to learn how developers manage code, track changes, and collaborate on projects. Through practical learning, you will discover how to create repositories, upload your projects, and publish your own website using GitHub Pages.

What You Will Learn 🚀

🔧 Git Basics

Learn version control, commits, branches, and how to track changes in your code.

🐙 GitHub Essentials

Create repositories, upload projects, and manage your code online.

🌐 GitHub Pages

Publish your HTML website online and share it with everyone.

🤝 Open Source

Understand pull requests, issues, and collaboration with other developers.
